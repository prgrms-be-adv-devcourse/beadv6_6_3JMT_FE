# PromptHub Admin Reference Rules

이 폴더는 구현 대상이 아니라 관리자 화면 비교 기준 원본이다.

- 먼저 README.md와 디렉터리 구조를 확인한다.
- 메뉴별 비교가 필요할 때 해당 JavaScript 파일만 읽는다.
- `assets/fonts` 바이너리는 읽지 않는다.
- 외부 라이브러리와 CDN 코드는 분석하지 않는다.
- 원본 코드를 그대로 복사하지 말고 Next.js App Router, TypeScript, Tailwind CSS 구조에 맞게 재구현한다.
